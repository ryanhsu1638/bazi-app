# 八字命書（純前端可安裝版）

不用 npm、不用終端機、不用後端伺服器。純 HTML + CSS + JS，打開 `index.html`
就能用，並且可以安裝到手機主畫面，成為一個離線可用的 App。

## 這個版本跟原本規劃的差異

| 項目 | 原規劃 | 這個簡化版 |
|---|---|---|
| 技術架構 | React + Vite + Supabase | 純 HTML/CSS/JS，無需建置 |
| 資料儲存 | Supabase 雲端資料庫 | IndexedDB（純本機，只存在您的裝置） |
| 會員系統 | Email/Google 登入 | 無需登入，資料自動留在本機 |
| 付費解鎖 | 銀行匯款＋後台審核 | 輸入兌換碼即可解鎖（見下方說明） |
| AI 分析 | 可切換 OpenAI/Claude/Gemini | 純前端規則引擎，不連網也能運作 |

## 功能

- ✅ 八字排盤：年柱／月柱以「節氣」精確計算（非農曆初一），日柱用連續干支曆推算
  - 已用兩筆獨立公開命例交叉驗證排盤結果完全正確
- ✅ 命盤顯示：四柱、天干地支、藏干、十神、五行比例圖、納音
- ✅ 神煞：8種（桃花、驛馬、華蓋、將星、天乙貴人、文昌、羊刃、紅艷、魁罡），
  採「年支+日支雙重參照」與「四柱重複出現次數」計算強度分數，由影響最大排到最小，
  避免過去只用單一參照導致大量使用者結果雷同的問題
- ✅ 免費內容：四柱、五行、基礎性格分析（含日主本性 + 身強身弱補充說明）
- ✅ **日元格局**（免費展示，提升解鎖興趣）：顯示日元屬性（如「庚金」）與特殊格局判斷
  （專旺格如曲直格/炎上格、從格如從財格/從殺格、特殊組合格局如殺印相生/官印相生/
  食神制殺/傷官配印/財多身弱，多數命盤則屬於一般的「正格」）
- ✅ **格局成就特質**（解鎖內容）：說明該格局歷史上常見對應的「角色典型」與背後原理
  （例如殺印相生格對應「亂世中臨危受命的統帥型人物」），刻意不指名具體真實歷史人物
  （見下方說明）
- ✅ 付費內容（兌換碼解鎖）：天賦分析、事業方向、感情策略（男女分流）、**財富運勢（含財富等級徽章、財庫分析）**、健康提醒
  — 每個區塊都結合多重排盤線索交叉判斷（主導十神 + 所在柱位人生階段 + 官殺/財星強弱 +
  夫妻宮十神 + 財庫有無/是否逢沖 + 五行最弱項提醒等），內容為多段落深度分析，不是單句話
- ✅ **合盤配對**：選擇歷史命盤中的自己，輸入對方出生資料，依日主五行生克、
  年支/日支合沖刑、**年柱納音合婚**判斷產生配對評分與建議（完整分析同樣用兌換碼解鎖）
- ✅ **五行喜用建議**：依日主五行 × 出生月份（已細分辰戌丑未四個土月），提示簡化版
  「喜用神」參考，正確處理四季土月的墓庫關係與五行流通變化（免費內容）
- ✅ 歷史命盤：可重複查看，存於本機 IndexedDB，**可個別刪除**（刪除前會跳出確認，避免手滑誤刪）
- ✅ 合盤配對的對方資料，可選擇**從歷史命盤中挑選**，或**手動輸入**新的一筆
- ✅ PWA：可安裝到 Android／iPhone 主畫面，支援離線使用

## 本機測試（不用裝任何東西）

方法一：直接雙擊 `index.html` 用瀏覽器打開即可看到畫面。

> 注意：直接用 `file://` 打開時，Service Worker（離線快取）與部分瀏覽器的
> IndexedDB 權限可能受限，建議測試「安裝」與「離線」功能時改用方法二。

方法二（推薦）：用簡易本機伺服器開啟，才能完整測試安裝與離線功能。
若電腦有裝 Python：

```bash
cd bazi-pwa
python3 -m http.server 8080
```

然後瀏覽器打開 `http://localhost:8080`。

## 部署到 GitHub Pages（讓手機可以真的安裝）

1. 到 [github.com](https://github.com) 新增一個 Repository（例如命名為 `bazi-app`）
2. 把這個資料夾（`bazi-pwa` 內的所有檔案，包含 `index.html`、`manifest.json`、
   `service-worker.js`、`css/`、`js/`、`icons/`）上傳到該 Repository 的根目錄
   - 最簡單的方式：在 GitHub 網頁上點「Add file → Upload files」，把整個資料夾內容拖曳上去
3. 進入 Repository 的 **Settings → Pages**
4. 「Source」選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`，按 Save
5. 等 1-2 分鐘，GitHub 會給您一個網址，格式類似：
   `https://您的帳號.github.io/bazi-app/`
6. 用手機瀏覽器打開這個網址：
   - **Android（Chrome）**：畫面會跳出「加到主畫面」提示，或點右上角選單 →「安裝應用程式」
   - **iPhone（Safari）**：點下方分享圖示 →「加入主畫面」
7. 安裝完成後，手機主畫面會出現「八字命書」App 圖示，點開就是全螢幕運作，
   之後離線也能開啟使用（排盤運算全部在手機本機完成）。


## 為什麼「格局成就特質」不指名具體真實歷史人物？

命理典籍在討論格局時，常會援引歷史人物作為示範案例（例如「某某格局像某位歷史名人」），
但這類做法在事實查證上站不住腳：

- 絕大多數歷史人物的確切出生時辰並無可靠記載
- 不同命理書籍對同一位歷史人物，往往給出完全不同、互相矛盾的八字
- 等於是在用「無法查證的傳說」冒充精確的事實依據

本專案改用**「角色典型」**的呈現方式：描述這個格局背後的原理，以及歷史上這類特質
常見對應到哪一種「角色定位」（例如「亂世中臨危受命、力挽狂瀾的統帥型人物」），
而不編造特定真人的出生資料或八字內容。這樣既能保留「格局對應成就類型」的
啟發性與吸引力，也不會有杜撰史實的風險。

## 日元格局判斷邏輯說明

傳統命理「格局」理論流派眾多、規則精細，本功能為簡化版判斷，依優先順序檢查：

1. **專旺格（一行得氣）**：同類五行力量極度旺盛（≥45%）且幾乎無官殺剋制（≤6%），
   依日主五行對應：木→曲直格、火→炎上格、土→稼穡格、金→從革格、水→潤下格
2. **從格**：日主力量極度虛弱（支援力量≤10% 且與消耗力量差距≤-30），
   命局氣勢一面倒向財星／官殺／食傷，分別對應從財格／從殺格／從兒格
3. **特殊組合格局**：殺印相生、官印相生、食神制殺、傷官配印、財多身弱、身強財旺，
   依財星/官殺/印星/食傷的力量比例與強弱組合判斷
4. **正格**：以上皆不符合時，依命盤中最鮮明的十神命名（多數人屬於此類，是命理常態）

這是本專案自行設計的簡化判斷方式，用於免費版展示一個具體、吸引人的初步印象，
完整精確的格局判斷在傳統命理中還會綜合考量月令司權、四柱組合細節等更多因素，
僅供參考，非命理定論。

## 財富等級與財庫分析說明

**財庫**是正統命理概念：財星（我剋者為財）所屬五行的「墓庫」地支
（十二長生表通行版本：木庫在未、火庫在戌、金庫在丑、水庫在辰，
土依「火土同宮」通行說法與火共用庫地在戌）。若這個地支出現在命盤四柱中，
代表天生有「存放財富的容器」；若這個財庫同時被其他地支「六沖」，
傳統上稱為「財庫逢沖」，代表財務上容易有較大金額的一次性進出。

**財富等級**則是本專案自行設計的綜合評分方式（並非傳統命理中單一固定的技法），
綜合以下三項計算：
1. 財星強弱（依五行力量比例判斷：旺／中等／偏弱／極弱）
2. 日主強弱是否能擔財（身強財旺加分；身弱財旺則反映「財多身弱」的風險，適度扣分）
3. 財庫有無（有財庫加分，財庫落在日柱或時柱再額外加分）

綜合分數對應到「上等財格／中上財格／中等財格／平穩發展型／需主動創造型」五個等級，
僅供趣味參考，並非命理定論或對個人財務能力的絕對評價。

## 神煞判斷邏輯說明

早期版本只用「日支」單一參照查三合局，且僅有3種神煞，12個地支只會分到
4種結果組合，導致大量使用者算出來的神煞完全相同。目前版本已改進：

1. **雙重參照**：桃花／驛馬／華蓋／將星同時用「年支」與「日支」各查一次
   （傳統上兩種參法皆可成立，年支與日支未必屬於同一組三合局，能產生更多變化）
2. **擴充至8種**：新增天乙貴人、文昌、羊刃、紅艷、魁罡（皆為日干或日柱本身查定）
3. **強度評分**：依「該神煞的目標地支在四柱中重複出現的次數」與「是否經雙重參照
   皆印證同一結果」計算分數，分數最高者排在最前面，並標示為「命主最具影響力」

排序後的結果代表：出現在越多柱（尤其是日柱／時柱，代表自身與親密關係、晚年）、
或經過兩種參照方式都指向同一結果的神煞，對命主的影響被視為越顯著。

## 合盤配對演算法說明

採用傳統命理中最通行、規則最明確的簡化合婚方法：

1. **雙方日主五行生克關係**（相生／相同／相剋）－ 影響感情根基的權重最高
2. **雙方年支關係**（六合／三合／六沖／相刑／平和）－ 反映家庭背景與大方向的契合度
3. **雙方日支關係**（六合／三合／六沖／相刑／平和）－ 日支代表夫妻宮，
   對親密關係與日常相處影響較大，因此權重加倍計算
4. **雙方年柱納音合婚**（納音五行生克關係，出自《三命通會》通行版本）－
   輔助判斷維度，權重低於日主

四項合併換算成 0-100 的參考分數。

**請注意**：完整的傳統合婚方法流派眾多，通常還會參考雙方大運、命宮、
用神是否互補等更複雜的因素。這個簡化版本適合作為**趣味參考**，
不代表窮盡所有命理合婚要素，也不構成感情關係好壞的絕對定論。

## 五行喜用建議說明

依「日主五行 × 出生月份」提供簡化版的喜用神參考（傳統命理概念是不同月份出生的人，
五行會偏冷/偏熱/偏燥/偏濕，或旺或弱，需要對應的五行來平衡，這個概念傳統上稱為「調候」
或「扶抑」）。

**這個版本已修正「四個土月」的處理方式**：辰、未、戌、丑是土當令的「季月」，
分別是水、木、火、金的「墓庫」（收藏之地），不能直接併入前一個季節計算，
本功能改採 **8 個節氣區段**獨立判斷（寅卯／辰／巳午／未／申酉／戌／亥子／丑），
明確納入每個土月對應的墓庫五行與五行流通變化。

這是**原創簡化版本**（依日主五行 5 種 × 8 個節氣區段，共 40 組），文字說明由本專案
自行撰寫，並非參考坊間特定命理師的品牌化內容（例如坊間流傳的「餓命學」是
特定命理師的自創命名與品牌化建議清單，本功能核心概念雖同樣源自傳統「調候」，
但內容、分類方式與計算邏輯完全獨立撰寫，並未引用其命名或建議清單）。

完整的傳統喜用神理論會精確到「日主天干 × 出生月份」共 120 種組合，
並綜合考量四柱其餘干支的互動（例如原局是否已透干相關五行、有無合化等），
本功能僅為簡化參考，並非命理定論。

## 排盤準確度說明

- 節氣計算使用天文學通用的太陽視黃經近似公式，經與公開發布的節氣時刻比對，
  誤差約在 15-20 分鐘內，足以正確判斷「日期」層級的年柱／月柱交界。
- 極少數情況下，若出生時刻剛好落在節氣交界前後 20 分鐘內，可能出現邊界誤判，
  屬於已知限制。
- 日柱計算錨點已用兩筆獨立公開命例交叉驗證（1980-03-10 12:00 與
  2000-01-01 08:00，北京時間），排盤結果完全正確。

## 之後想擴充怎麼辦？

- **想串接真正的 AI（GPT/Claude）分析文字**：修改 `js/ai-rules.js` 的
  `generateFullAnalysis()`，改成 `fetch()` 呼叫您的 AI API（需要另外架一個
  小型後端代理來保護 API 金鑰，不能把金鑰直接寫在前端程式碼裡）。
- **想要真的收款而不是兌換碼**：可以串接金流的付款連結，付款成功後由您
  手動告知使用者兌換碼即可，不需要大改架構。
- **想要跨裝置同步歷史命盤**：那就會需要回到原本規劃的 Supabase 後端版本。
